# Scraps roadmap

## Accepted objective

Build a mechanically exact swordfighting foundation and tune it against gameplay references. First build: browser, AI opponents, warm restrained retro presentation. The pirate world is a pre-match lobby only. Standard duel fidelity precedes roguelite development.

## First build delivered surface

- AI duel and solo practice, local opponent records, optional duel view.
- Fully remappable controls; adjustable feel constants.
- Deterministic board/attack engine and input replays.
- Freebuild, practice setups, explicit break results, attack experiments.
- Pattern creator, import/export and legacy blade layouts.

## Immediate fidelity backlog

1. Verify current Saber and Falchion arrays, add them beside the preserved legacy versions.
2. Build timestamped fixtures for penetration by width/length, fused obstacles, horizontal conversion and attack scheduling.
3. Measure fast fall, natural fall, lock and animation transitions against uncut gameplay.
4. Resolve simultaneous fusion and chain ordering edge cases, then add golden fixtures.
5. Improve AI setup depth and defence with a reproducible benchmark based on comparable board states. Do not claim tournament parity from wins against the existing bot.
6. Browser interaction/visual testing, including narrow screens, focus, controls and stored data paths.

## After duel acceptance

- Roguelite: encounters, run state, rewards and build choices, isolated from standard rules.
- Endless mode and expanded practice puzzle library.
- Custom rule profiles with separate records and replay metadata.
- Online 1v1 with authoritative simulation and reconnect handling.
- Ranked ladder, spectator mode, tournaments and cosmetics.

No fake multiplayer population, ladder or placeholder purchases in the first build. Progression must not alter standard duel calculations.
